# Security

node-craft contains guidance and test fixtures, not a running service. Still, advice in it can lead to insecure
backends if it is wrong.

If you find guidance that would create a vulnerability (for example a missing authorization check in an example, or a
webhook verification that is not what the provider documents), please report it privately through GitHub's
**Report a vulnerability** button on the repository's Security tab, instead of a public issue.

Please include the file and section, why it is unsafe, and the safe alternative if you know it. We aim to respond
within a week.
