How the skills work together

Every task starts from the project's own decisions and ends with checks that actually ran.
Each skill opens only the reference files the task needs.

1 · READ THE PROJECT

Its decisions win

  • AGENTS.md · CLAUDE.md
  • STACK.md and docs/adr/
  • Framework, ORM, auth, package manager already in use
  • Current test results, recorded before any change

New project? node-craft-init makes these decisions from the product and writes them down.

2 · CORE SKILL

node-craft

  • Red → Green → Refactor
  • Never weaken a test to get green
  • Optional services only when needed
  • The server is the authority
  • Definition of done
  • Report only what ran
